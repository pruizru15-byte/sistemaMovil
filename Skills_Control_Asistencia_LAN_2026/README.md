# Paquete de 12 skills para agentes — Control de Asistencia LAN

**Contenido:** `AGENTS.md`, 12 carpetas `.agents/skills/` con `SKILL.md` y checklist, 8 documentos en `docs/`.

**Instalación:** descomprimir en la raíz del repositorio del sistema y pedir al agente que lea `AGENTS.md` antes de trabajar. Este paquete contiene instrucciones y documentación, **no un proyecto ejecutable ni código de aplicación**.

**Acceso web:** permitido para consultar documentación oficial durante desarrollo. La APP y API funcionarán sólo sobre Wi-Fi local sin nube ni conexión WAN.

**Inicio recomendado:** leer `docs/REQUISITOS.md`, decidir tareas y seguir `docs/GUIA_AGENTES.md`. Fijar versiones y lockfiles al crear el proyecto.
